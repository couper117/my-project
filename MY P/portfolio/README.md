# ISHIMWE KENY KELVIN — Portfolio

A production-ready, fully editable portfolio inspired by landonorris.com. One file: `index.html` (HTML + CSS + JavaScript, GSAP animations). No build step, no server needed.

## Open it
Double-click `index.html` — it runs in any modern browser.

## Edit anything (no code needed)
1. Click **✎ Edit Site** (bottom-right).
2. Click any text and type to change it. Use `**word**` to make a word lime/bold in the quote sections.
3. Click any image (hero photo, gallery photos, project images) to replace it — paste a URL, or leave blank to upload a file from your computer.
4. **✕** removes an item; **+ Add** buttons add photos, projects, skills, and social links.
5. Click **✓ Save**. Changes are stored in your browser (localStorage) and survive refreshes.

**Export JSON** downloads all your content as a backup file; **Import JSON** restores it (use this to move your edits to another browser/computer). **Reset** returns everything to defaults.

⚠️ The gallery ships with placeholder photos hotlinked from landonorris.com so you can see the exact animation style — replace them with your own photos before publishing (they're Lando's copyrighted images).

## Publish free on GitHub Pages
1. Create a repo (e.g. `couper117.github.io`) and upload `index.html`.
2. Repo Settings → Pages → Deploy from branch → `main` → root.
3. Your site goes live at `https://couper117.github.io`.

Note: localStorage edits live in *your* browser only. To make edits permanent for all visitors, make your changes, **Export JSON**, then open `index.html` in an editor and paste the exported content over the `DEFAULT_DATA` object — then re-upload.

## What's inside
Preloader counter ("Load Kelvin"), letter-reveal hero, marquee strips, pinned horizontal-scroll gallery with parallax, word-by-word quote reveals, ON CODE / OFF CODE split, projects grid with hover effects (linked to your GitHub repos), tech-stack marquees, socials list, lime footer — all matching the landonorris.com animation language.
